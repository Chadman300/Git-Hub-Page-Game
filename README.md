# Git-Hub-Page-Game

A bullet hell top-down shooter game that runs in your browser!

## How to Play

Simply open `index.html` in your web browser to start playing.

**Controls:**
- WASD or Arrow Keys - Move your ship
- SPACE - Shoot
- Avoid enemy bullets and defeat waves of enemies!

## Custom Protocol Launcher

You can also set up a custom protocol handler to launch the game using `externalfile://` URLs!

This allows you to:
- Launch the game from anywhere using custom URLs
- Integrate with other applications
- Create shortcuts and bookmarks

**See [LAUNCHER-SETUP.md](LAUNCHER-SETUP.md) for detailed setup instructions.**

Quick setup:
```bash
node register-protocol.js
```

Then follow the instructions for your operating system!
